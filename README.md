# CASE00A｜AIと世界史年表を作る

3650 LAB のプロトタイプCASE。1450〜1800年ヨーロッパを対象に、出来事の暗記ではなく「なんで次につながった？」をたどるブラウザMVPです。

## Live MVP

https://boqxxxpod-debug.github.io/case00a-ai-world-history-timeline/

## MVP v0.5

v0.4で「読む → 地図で確認」の体験が固まったので、v0.5では**49ステップの中身をもう一段深く**しました。

基本の使い方は同じです。

**右ペインで歴史を読む → “へえ”を拾う → 左の因果マップで現在地を確認する**

### v0.5で増やしたもの

各ストーリーに3〜5個以上、次の深掘りカードを追加しています。

- 📏 **数字で見ると**：規模感が分かる数字
- 😮 **え、そうなの？**：よくあるイメージを少しひっくり返す話
- ⚖️ **ここ、割れてます**：歴史家の競合理論や因果の向きの論争
- 🧠 **仕組みで見ると**：制度・市場・信用など、裏側のメカニズム
- 🔎 **もう一段だけ**：本文だけでは省いた補足

### 追加した主な「へえ」

- ST01：宗教改革期のウィッテンベルク出版量の急増、1520年代の巨大なパンフレット市場
- ST02：1555年の宗教和議は現代的な信教の自由ではない、プラハ窓外放出で3人が生還、1648年＝主権国家誕生説への批判
- ST03：対仏戦争の年間戦費、戦争資金のために生まれたイングランド銀行、Window Tax
- ST04：Philosophical Transactionsは1665年に1シリングの月刊として始まり、初期はHenry Oldenburgの個人出版に近かった
- ST05：ワットが見つけた大きな熱損失、分離凝縮器による燃料節約、発明から商用化までの長い時間、1800年までのBoulton & Watt製造数
- ST06：高賃金・安価な石炭説、消費革命の社会的偏り、帝国・奴隷制の寄与をめぐる大きな論争、アークライトの“孤独な天才”像の見直し

深掘りカードにはそれぞれ**「ほんと？ 根拠を見る」**を付け、研究・博物館・公的機関などの出典へ進めます。

### 6つのストーリー

- ST01｜印刷で宗教が爆速？
- ST02｜宗教で国が変わる？
- ST03｜戦争代、どう払う？
- ST04｜科学は工場につながる？
- ST05｜炭鉱の水 → 蒸気
- ST06｜産業革命、結局なに？

全49ステップです。

## フローが途切れて見える場所について

歴史的に直接因果を置きにくい区間を、無理に矢印でつなぐことはしていません。

代わりに右ペインで、

- なぜ直接線を置いていないのか
- 間にどんな政治・制度・市場・社会の変化があるのか
- どこから先が歴史学上の論争なのか
- 因果の向きが逆にも考えられるのか

を説明します。

つまり、**「線がない＝関係がない」ではなく、「直接因果としては強く言えないので、読み物で橋をかける」**という設計です。

## 基準データ

歴史グラフの基準データは引き続き **38ノード / 35因果リンク**です。v0.5でも基準グラフは増やさず、その上の「読み物・研究レイヤー」を強化しています。

## 基本機能

- 1450〜1800年の年表
- 38ノード / 35因果リンク
- 5テーマ（印刷 / 宗教改革 / 国家 / 科学 / 産業）
- ノード・因果リンクのクリック詳細
- 因果強度：かなり強い / つながりあり / 意見が分かれる
- ST01〜ST06 の6つの深掘りストーリー
- 各ステップから「地図で確認」
- 研究深掘りカード
- 根拠・出典リンク

静的HTML/CSS/JavaScriptのみで動作します。
