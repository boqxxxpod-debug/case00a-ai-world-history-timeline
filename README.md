# CASE00A｜AIと世界史年表を作る

3650 LAB のプロトタイプCASE。1450〜1800年ヨーロッパを対象に、出来事の暗記ではなく「なんで次につながった？」をたどるブラウザMVPです。

## Live MVP

https://boqxxxpod-debug.github.io/case00a-ai-world-history-timeline/

## MVP v0.6

v0.5で49ステップの内容を深くしたので、v0.6では**6つのストーリーを1本の大きな旅としてつなぐ**ことに集中しました。

基本の体験は、

**右ペインで読む → “へえ”を拾う → 左の因果マップで現在地を確認 → 次の章へ進む**

です。

### v0.6で変えたこと

- 6章を横断する「全体ルート」を追加
- いま第何章か、全49ステップ中どこまで来たかを表示
- 章同士のつながり方を明示
  - ST01 → ST02：因果的につながる
  - ST02 → ST03：国家形成の話から英国の戦費調達へズーム
  - ST03 → ST04：直接因果ではなく、同時代の並行ルートへ視点移動
  - ST04 → ST05：知識の世界から現場の技術へ
  - ST05 → ST06：複数条件を因果のハブへ合流
- 各章の冒頭に「前の章からどう来た？」を追加
- 各章の最後に「ここから次へ」を追加
- 前章／現在章／次章をいつでも確認・移動できるナビを追加

特にST03 → ST04は、**金融革命が科学革命を起こしたわけではない**ため、あえて「並行ルート」と表示します。6章を一本の“偽の因果チェーン”にしないための設計です。

### 6つの章

1. ST01｜印刷で宗教が爆速？
2. ST02｜宗教で国が変わる？
3. ST03｜戦争代、どう払う？
4. ST04｜科学は工場につながる？
5. ST05｜炭鉱の水 → 蒸気
6. ST06｜産業革命、結局なに？

全49ステップです。

## v0.5で追加した深掘り

各ストーリーに3〜5個以上、次の深掘りカードがあります。

- 📏 **数字で見ると**：規模感が分かる数字
- 😮 **え、そうなの？**：よくあるイメージを少しひっくり返す話
- ⚖️ **ここ、割れてます**：歴史家の競合理論や因果の向きの論争
- 🧠 **仕組みで見ると**：制度・市場・信用など、裏側のメカニズム
- 🔎 **もう一段だけ**：本文だけでは省いた補足

深掘りカードには**「ほんと？ 根拠を見る」**を付け、研究・博物館・公的機関などの出典へ進めます。

## フローが途切れて見える場所について

歴史的に直接因果を置きにくい区間を、無理に矢印でつなぐことはしていません。

代わりに右ペインで、

- なぜ直接線を置いていないのか
- 間にどんな政治・制度・市場・社会の変化があるのか
- どこから先が歴史学上の論争なのか
- 因果の向きが逆にも考えられるのか

を説明します。

つまり、**「線がない＝関係がない」ではなく、「直接因果としては強く言えないので、読み物で橋をかける」**という設計です。

## 基準データ

歴史グラフの基準データは引き続き **38ノード / 35因果リンク**です。基準グラフは増やさず、その上の「読み物・研究レイヤー」を強化しています。

## 基本機能

- 1450〜1800年の年表
- 38ノード / 35因果リンク
- 5テーマ（印刷 / 宗教改革 / 国家 / 科学 / 産業）
- ノード・因果リンクのクリック詳細
- 因果強度：かなり強い / つながりあり / 意見が分かれる
- ST01〜ST06 の6つの深掘りストーリー
- 49ステップの全体ルート
- 各ステップから「地図で確認」
- 研究深掘りカード
- 根拠・出典リンク

静的HTML/CSS/JavaScriptのみで動作します。
