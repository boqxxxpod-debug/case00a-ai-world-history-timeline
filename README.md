# CASE00A｜AIと世界史年表を作る

3650 LAB のプロトタイプCASE。1450〜1800年ヨーロッパを対象に、出来事の暗記ではなく「なんで次につながった？」をたどるブラウザMVPです。

## Live MVP

https://boqxxxpod-debug.github.io/case00a-ai-world-history-timeline/

## MVP v0.4

v0.3で6ストーリーを深掘りしたあと、今回は**読む体験そのもの**を磨きました。

基本の使い方は変わりません。

**右ペインで歴史を読む → 気になったら左の因果マップで現在地を確認する**

### v0.4で変えたこと

- 右ペインをさらに広くして、読み物を主役にした
- 各ストーリーの最初に「今回の問い」を表示
- 「へえポイント」をさらにカジュアルな言い方へ変更
- 直接の矢印がないステップでは「地図に線がないけど？」と理由を説明
- 矢印が複数集まる場所では「一本道じゃない」と明示
- 読み終えたステップにチェックを付ける
- 各ストーリーの最後に「3行で持ち帰るなら」を追加
- 出典は「ほんと？ 出典を見る」として必要なときだけ開ける

### 6つのストーリー

- ST01｜印刷で宗教が爆速？
- ST02｜宗教で国が変わる？
- ST03｜戦争代、どう払う？
- ST04｜科学は工場につながる？
- ST05｜炭鉱の水 → 蒸気
- ST06｜産業革命、結局なに？

全49ステップ。各ステップには本文、**「ここ、ちょっと面白い」**、次へのつながり、対応する地図上のノード／リンク、出典があります。

### フローが途切れて見える場所について

歴史的に直接因果を置きにくい区間を、無理に矢印でつなぐことはしていません。

代わりに右ペインで、

- なぜ直接線を置いていないのか
- 間にどんな政治・制度・市場・社会の変化があるのか
- どこから先が歴史学上の論争なのか

を説明します。

つまり、**「線がない＝関係がない」ではなく、「直接因果としては強く言えないので、読み物で橋をかける」**という設計です。

## 基準データ

歴史グラフの基準データは引き続き **38ノード / 35因果リンク**です。深掘り版はこの基準グラフを勝手に増やさず、その上に「読み物レイヤー」を載せています。

## 基本機能

- 1450〜1800年の年表
- 38ノード / 35因果リンク
- 5テーマ（印刷 / 宗教改革 / 国家 / 科学 / 産業）
- ノード・因果リンクのクリック詳細
- 因果強度：かなり強い / つながりあり / 意見が分かれる
- ST01〜ST06 の6つの深掘りストーリー
- テーマ ON/OFF
- 各ステップから「地図で確認」
- 根拠・出典リンク

静的HTML/CSS/JavaScriptのみで動作します。
