# CASE00A｜AIと世界史年表を作る

3650 LAB のプロトタイプCASE。1450〜1800年ヨーロッパを対象に、出来事だけでなく因果関係の分岐・合流を探索するブラウザMVPです。

## Live MVP

https://boqxxxpod-debug.github.io/case00a-ai-world-history-timeline/

## MVP v0.2

v0.1のレビューを受けて、「巨大なフロー図を読む」よりも「右ペインで歴史を一歩ずつたどり、フロー図で現在地を確認する」体験を試しています。

### ST01 深掘りプロトタイプ

「印刷がなかったら、宗教改革はここまで広がった？」を8ステップで読み進めます。

- 印刷技術だけでは革命にならなかった
- 初期の印刷業はカトリック教会の需要にも支えられていた
- 1517年にはすでに情報を増幅できる印刷インフラがあった
- 宗教論争がパンフレット市場を成長させ、印刷と宗教改革が相互に増幅した
- 低い識字率でも、朗読・画像・歌などを通じて印刷物の内容は広がり得た
- 都市データから印刷所とプロテスタント化の関係を測った実証研究も紹介
- 「印刷が宗教改革を起こした」ではなく「印刷が強力な増幅器になった」と整理
- ST01の終点からST02へつなぐ

各ステップで、対応する既存ノード／因果リンクを左のフロー図上で強調します。読み筋を深くしても、歴史グラフの38ノード／35リンクという基準データ自体は変更していません。

## 基本機能

- 1450〜1800年の年表
- 38ノード / 35因果リンク
- 5 lane（印刷 / 宗教改革 / 国家 / 科学 / 産業）
- ノード・因果リンクのクリック詳細
- STRONG / MEDIUM / DEBATED の視覚的区別
- ST01〜ST06 の6つの因果ストーリー切替
- lane ON/OFF
- DEBATEDリンクで研究上の論争を明示

静的HTML/CSS/JavaScriptのみで動作します。
