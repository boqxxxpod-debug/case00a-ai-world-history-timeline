# CASE00A｜AIと世界史年表を作る

3650 LAB のプロトタイプCASE。1450〜1800年ヨーロッパを対象に、出来事の暗記ではなく「なんで次につながった？」をたどるブラウザMVPです。

## Live MVP

https://boqxxxpod-debug.github.io/case00a-ai-world-history-timeline/

## MVP v0.3

v0.2のレビューを受けて、主役をさらに入れ替えました。

**右ペインで歴史を読む → 気になったら左の因果マップで現在地を確認する**のが基本操作です。

ST01〜ST06をすべて深掘り版にしました。

- ST01｜印刷で宗教が爆速？
- ST02｜宗教で国が変わる？
- ST03｜戦争代、どう払う？
- ST04｜科学は工場につながる？
- ST05｜炭鉱の水 → 蒸気
- ST06｜産業革命、結局なに？

各ストーリーは7〜10前後の短いステップで読み進めます。各ステップには、本文、**「へえポイント」**、次へのつながり、対応する地図上のノード／リンク、出典を用意しています。

### フローが途切れて見える場所について

歴史的に直接因果を置きにくい区間を、無理に矢印でつなぐことはしていません。

代わりに右ペインで、

- なぜ直接線を置いていないのか
- 間にどんな政治・制度・市場・社会の変化があるのか
- どこから先が歴史学上の論争なのか

を説明します。

例：アウクスブルクの宗教和議 → 三十年戦争は、一本の直接因果にはせず、宗派形成・同盟・帝国憲政・王朝政治を間に置いて読みます。

## 基準データ

歴史グラフの基準データは引き続き **38ノード / 35因果リンク**です。深掘り版はこの基準グラフを勝手に増やさず、その上に「読み物レイヤー」を載せています。

## 基本機能

- 1450〜1800年の年表
- 38ノード / 35因果リンク
- 5テーマ（印刷 / 宗教改革 / 国家 / 科学 / 産業）
- ノード・因果リンクのクリック詳細
- 因果強度：かなり強い / つながりあり / 意見が分かれる
- ST01〜ST06 の6つの深掘りストーリー
- テーマ ON/OFF
- 各ステップから「地図で見る」
- 根拠・出典リンク

静的HTML/CSS/JavaScriptのみで動作します。
