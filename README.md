# CASE00A｜AIと世界史年表を作る

3650 LAB のプロトタイプCASE。1450〜1800年ヨーロッパを対象に、出来事の暗記ではなく「なんで次につながった？」をたどるブラウザMVPです。

## Live MVP

https://boqxxxpod-debug.github.io/case00a-ai-world-history-timeline/

## MVP v0.9

v0.8までで「読む → 地図で確認 → 6章まとめ」という体験が固まったため、v0.9では**見た目を増やさず、コード構造と実装の整合性を整理**しました。

基本の体験は変えていません。

**右ペインで読む → “へえ”を拾う → 左で「今どこ？」を確認 → 最後に6章まとめで振り返る**

## 6つの章

1. ST01｜印刷で宗教が爆速？
2. ST02｜宗教で国が変わる？
3. ST03｜戦争代、どう払う？
4. ST04｜科学は工場につながる？
5. ST05｜炭鉱の水 → 蒸気
6. ST06｜産業革命、結局なに？

全49ステップです。

## このMVPで一番持ち帰りたいこと

**歴史は「AがBを起こした」の一本線より、増幅・分岐・並行・ボトルネック・合流として見ると面白くなる。**

## 基準データ

歴史グラフの基準データは引き続き **38ノード / 35因果リンク**です。v0.9はリファクタリング版なので、歴史ノード・因果リンク・49ステップの内容は増やしていません。

## 基本機能

- 1450〜1800年の年表
- 38ノード / 35因果リンク
- 5テーマ（印刷 / 宗教改革 / 国家 / 科学 / 産業）
- ノード・因果リンクのクリック詳細
- 因果強度：かなり強い / つながりあり / 意見が分かれる
- ST01〜ST06 の6つの深掘りストーリー
- 49ステップの全体ルート
- 数字・意外な話・論争を示す深掘りカード
- 直接因果を置けない場所の「読み物で橋渡し」表示
- 文脈つき因果マップ（通った / いま / つぎ / この章の先）
- 「今ここへ」
- 6章まとめ
- 根拠・出典リンク

静的HTML/CSS/JavaScriptのみで動作します。
