## v1.0で確定した体験

**READ → WOW → MAP → NEXT → REVIEW**

- **READ**｜右ペインで因果ストーリーを一歩ずつ読む
- **WOW**｜数字・意外な背景・競合理論・仕組みから「へえ」を拾う
- **MAP**｜左の因果マップで現在地と全体像を確認する
- **NEXT**｜次の因果へ進む
- **REVIEW**｜最後に6章まとめで350年をつなぎ直す

CASE00A開始時は「巨大な因果グラフそのもの」を主役に想定していました。実験後の結論は、**グラフは読む主役ではなく、理解した内容を置き直す地図として使う方がよい**、でした。

## 基準データ

- 1450〜1800年
- 38ノード
- 35因果リンク
- 5テーマ（印刷 / 宗教改革 / 国家 / 科学 / 産業）
- 因果強度：かなり強い / つながりあり / 意見が分かれる

基準グラフを無理に増やさず、その上に読み物・研究・表示レイヤーを載せています。直接因果を強く言えない区間は、見栄えのために矢印を追加せず、読み物で橋渡しします。

## このCASEで得た型

### CONTENT MODEL

基準ノード → 基準因果リンク → 因果強度 → 5〜8本の因果ストーリー → 7〜10ステップ化 → 「何が起きた / なぜ次へ / ここが面白い / 数字・逆説・競合理論・メカニズム / 出典」 → 全体まとめ。

### HISTORICAL RULE

- 弱い因果を見栄えのために強くしない
- 直接矢印を引けないところは読み物で橋渡し
- DEBATEDを欠点ではなく学びとして見せる
- 「誕生日」「単独原因」「一直線」を疑う
- 数字は驚かせるためではなく規模感を与えるために使う
