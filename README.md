# CASE00A｜AIと世界史年表を作る

3650 LAB のプロトタイプCASE。1450〜1800年ヨーロッパを対象に、出来事の暗記ではなく「なんで次につながった？」をたどるブラウザMVPです。

## Live MVP

https://boqxxxpod-debug.github.io/case00a-ai-world-history-timeline/

## MVP v0.7

v0.6で6章を1本の旅としてつないだので、v0.7では**左の因果マップを「読んだあとに見ると意味が分かる地図」へ改善**しました。

基本の体験は、

**右ペインで読む → “へえ”を拾う → 左で「今どこ？」を確認 → 次へ進む**

です。

### v0.7で変えたこと

- 章を選ぶと、その章で使うノード／リンクを地図上で文脈表示
- 地図上で状態を分ける
  - ✓ 通った場所
  - ● いま読んでいる場所
  - ○ 次に見る場所
  - 薄く表示：この章の先
  - かなり薄く表示：今の章の外側
- ノードに「この章の何ステップ目で登場するか」の小さな番号を表示
- 「今ここへ」ボタンで、現在のノードを地図の中央へ移動
- 直接の因果リンクがないステップでは、地図側にも「ここは読み物で橋渡し」と表示
- 矢印が3本以上集まるステップでは「一本道ではなく分岐・合流」と表示
- 右ペインを主役、左マップを“現在地確認”として明確に役割分担

### 6つの章

1. ST01｜印刷で宗教が爆速？
2. ST02｜宗教で国が変わる？
3. ST03｜戦争代、どう払う？
4. ST04｜科学は工場につながる？
5. ST05｜炭鉱の水 → 蒸気
6. ST06｜産業革命、結局なに？

全49ステップです。

## v0.6までの主な仕組み

- 6章を横断する全体ルート
- 全49ステップ中の現在地表示
- 章同士の関係を「因果／ズーム／並行ルート／現場へ／合流」と区別
- 各章の冒頭に「前の章からどう来た？」
- 各章の最後に「ここから次へ」
- 各ストーリーに3〜5個以上の深掘りカード
  - 📏 数字で見ると
  - 😮 え、そうなの？
  - ⚖️ ここ、割れてます
  - 🧠 仕組みで見ると
  - 🔎 もう一段だけ
- 深掘りカードから研究・博物館・公的機関などの出典へ移動

## フローが途切れて見える場所について

歴史的に直接因果を置きにくい区間を、無理に矢印でつなぐことはしていません。

代わりに右ペインで、

- なぜ直接線を置いていないのか
- 間にどんな政治・制度・市場・社会の変化があるのか
- どこから先が歴史学上の論争なのか
- 因果の向きが逆にも考えられるのか

を説明します。

v0.7では、この考え方を左の地図にも反映し、**「線がない＝関係がない」ではなく、「直接因果としては強く言えないので読み物で橋をかけている」**ことを地図側でも分かるようにしました。

## 基準データ

歴史グラフの基準データは引き続き **38ノード / 35因果リンク**です。v0.7でも基準グラフは増やさず、その上の「読み物・研究・表示レイヤー」を改善しています。

## 基本機能

- 1450〜1800年の年表
- 38ノード / 35因果リンク
- 5テーマ（印刷 / 宗教改革 / 国家 / 科学 / 産業）
- ノード・因果リンクのクリック詳細
- 因果強度：かなり強い / つながりあり / 意見が分かれる
- ST01〜ST06 の6つの深掘りストーリー
- 49ステップの全体ルート
- 文脈つき因果マップ
- 「今ここへ」
- 研究深掘りカード
- 根拠・出典リンク

静的HTML/CSS/JavaScriptのみで動作します。
