# CASE00A｜AIと世界史年表を作る

3650 LAB のプロトタイプCASE。1450〜1800年ヨーロッパを対象に、出来事の暗記ではなく「なんで次につながった？」をたどるブラウザMVPです。

## Live MVP

https://boqxxxpod-debug.github.io/case00a-ai-world-history-timeline/

## MVP v0.8

v0.7で「右で読む → 左で現在地を見る」が固まったので、v0.8では**6章を読み終えたあと、350年を1画面で振り返れるまとめ**を追加しました。

基本の体験は、

**右ペインで読む → “へえ”を拾う → 左で「今どこ？」を確認 → 最後に6章まとめで振り返る**

です。

### v0.8で変えたこと

- ストーリー選択に「🧭 6章まとめ」を追加
- 1450〜1800年の流れを「350年を6行で」表示
- 6章それぞれを次の3点で再整理
  - 何が起きた？
  - 何が意外？
  - 因果をどう見る？
- 各章カードから元のストーリーへ戻れる
- 全体で持ち帰る因果の見方を明示
  - 増幅
  - 長い制度変化
  - 困りごとから制度が生まれる
  - 知識の生態系
  - ボトルネックのリレー
  - 合流点
- まとめ画面からST01へ戻ってもう一周できる

### このMVPで一番持ち帰りたいこと

**歴史は「AがBを起こした」の一本線より、増幅・分岐・並行・ボトルネック・合流として見ると面白くなる。**

6章の要約は、基準グラフと既存の49ステップを再整理したもので、新しい歴史ノードや因果リンクは追加していません。

### 6つの章

1. ST01｜印刷で宗教が爆速？
2. ST02｜宗教で国が変わる？
3. ST03｜戦争代、どう払う？
4. ST04｜科学は工場につながる？
5. ST05｜炭鉱の水 → 蒸気
6. ST06｜産業革命、結局なに？

全49ステップです。

## v0.7までの主な仕組み

- 右ペイン中心の深掘りストーリー
- 左の因果マップで「通った／いま／つぎ／この章の先」を文脈表示
- 直接因果を置けない場所では「読み物で橋渡し」と明示
- 6章を横断する全体ルート
- 章同士の関係を「因果／ズーム／並行ルート／現場へ／合流」と区別
- 各章に数字・意外な話・競合理論・仕組みの深掘りカード
- 出典リンク

## フローが途切れて見える場所について

歴史的に直接因果を置きにくい区間を、無理に矢印でつなぐことはしていません。

代わりに右ペインで、

- なぜ直接線を置いていないのか
- 間にどんな政治・制度・市場・社会の変化があるのか
- どこから先が歴史学上の論争なのか
- 因果の向きが逆にも考えられるのか

を説明します。

## 基準データ

歴史グラフの基準データは引き続き **38ノード / 35因果リンク**です。v0.8でも基準グラフは増やさず、その上の「読み物・研究・表示・振り返りレイヤー」を改善しています。

## 基本機能

- 1450〜1800年の年表
- 38ノード / 35因果リンク
- 5テーマ（印刷 / 宗教改革 / 国家 / 科学 / 産業）
- ノード・因果リンクのクリック詳細
- 因果強度：かなり強い / つながりあり / 意見が分かれる
- ST01〜ST06 の6つの深掘りストーリー
- 49ステップの全体ルート
- 文脈つき因果マップ
- 「今ここへ」
- 研究深掘りカード
- 6章まとめ
- 根拠・出典リンク

静的HTML/CSS/JavaScriptのみで動作します。
